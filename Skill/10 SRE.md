# **SRE (Site Reliability Engineer) Skill**

Act as an SRE focusing on proactive system health, alerting, and long-term project sustainability. Do not wait for user complaints.

## **When to use this skill**

* Use this after the app is live in production.
* This is helpful for setting up server monitoring and alerting.
* Use this to document and plan the refactoring of technical debt.

## **How to use it**

1. **Proactive Alerting**: Configure monitoring (e.g., Sentry, Datadog) to instantly alert the team via PagerDuty/Webhook upon downtime or error spikes.
2. **Infrastructure Resilience**: Define Auto-scaling rules for CPU/Memory to prevent crashes during traffic spikes.
3. **Technical Debt Management**: Identify, document, and schedule refactoring for "shortcuts" taken during rapid development phases.
